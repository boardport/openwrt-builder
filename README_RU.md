Модульный сборщик прошивок OpenWRT на основе внешних оверлеев для встраиваемых плат, 4G/LTE-модемов и сетевых устройств.

Репозиторий входит в экосистему **[BoardPort](https://github.com/boardport)** и предоставляет чистый слой адаптации
поверх штатной сборочной системы OpenWRT без отслеживания тяжелых кодовых баз апстрима и засорения базовых исходников.

> 🤖 **Примечание для AI-ассистентов:** Автономные агенты и LLM-ассистенты обязаны ознакомиться с правилами проекта
> в файле [AGENTS_RU.md](./AGENTS_RU.md) перед началом работы в этом репозитории.

---

## 🎯 О проекте

Главная миссия **OpenWRT Builder** — оркестрация воспроизводимой контейнеризированной сборки прошивок OpenWRT,
сконфигурированных с учетом строгих аппаратных ограничений различных встраиваемых платформ:

- 📶 **Сотовые 4G/LTE USB-модемы и компактные роутеры:** мобильные шлюзы, USB-донглы и карманные точки доступа.
- 🧩 **Платы разработки и одноплатные компьютеры (SBC):** отладочные платы, комплекты разработчика и промышленные вычислительные модули.
- 📱 **Вторичное использование мобильных и встраиваемых платформ:** перепрофилируемые устройства в роли IoT-шлюзов или edge-маршрутизаторов.

### Архитектура репозитория

Проект организован как модульный оркестратор, координирующий изолированные подмодули:

- **`docker/` ([openwrt-docker](https://github.com/boardport/openwrt-docker)):** Многостадийные рецепты сборки контейнеров,
  предоставляющие изолированный тулбокс и предскомпилированные кросс-тулчейны (`aarch64_cortex-a53`, `x86_64` и др.).
- **`overlay/` ([openwrt-overlay](https://github.com/boardport/openwrt-overlay)):** Внешний аппаратно-зависимый оверлей с деревьями устройств (DTS),
  платформенными таргетами и драйверами.

## ⚡ Быстрый старт

Репозиторий включает готовый инструментарий автоматизации на базе Make:

### 1. Просмотр доступных команд

```bash
make help
make list
```

### 2. Сборка базового контейнера Toolbox

Сборка базового Debian-окружения со всеми необходимыми хостовыми утилитами сборки:

```bash
make openwrt-build-toolbox
```

### 3. Сборка предскомпилированного кросс-тулчейна

Сборка Docker-образа с готовым кросс-компилятором и инструментами под выбранную архитектуру:

```bash
# Архитектура по умолчанию: aarch64_generic (или явно укажите OPENWRT_ARCH=aarch64_cortex-a53)
make openwrt-build-toolchain OPENWRT_ARCH=aarch64_cortex-a53
```

### 4. Интерактивная разработка и конфигурирование

Запуск интерактивного терминала внутри контейнера или графического меню `menuconfig`:

```bash
# Запуск bash внутри контейнера с тулчейном
make openwrt-sh-toolchain OPENWRT_ARCH=aarch64_cortex-a53

# Запуск меню конфигурации OpenWrt
make openwrt-menuconfig OPENWRT_ARCH=aarch64_cortex-a53
```
